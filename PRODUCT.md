# Vivid Realms

## Platform

Web application for tabletop roleplaying, with player and GM workflows. The existing client is React and TypeScript; the server is TypeScript with SQLite persistence. Campaigns support Remnant and D&D 5e rules.

## Product facts

- Players and GMs use campaigns, character sheets, battle maps, dice rolls, and shop boards.
- The Emporium offers cosmetic discovery, purchases, and Vivid Cache rewards. Cache-only ownership rules remain authoritative on the server.
- Cosmetics include dice sets, dice trails, critical-roll effects, turn-start effects, token borders, and profile appearance items.
- Custom dice support colors, number treatments, patterns, and finishes. Players can save up to five custom dice presets, edit or delete them, and equip a selected design.
- The existing customizer provides a floating, draggable, slowly rotating 3D die, D4 through D20 shape selection, and test rolls.
- Table backdrop selection includes built-in backgrounds and image uploads. Background preference is currently saved on the device.

## Confirmed Customize redesign brief — 2 October 2026

The user wants a full layout and color redesign, with easier navigation and clear access to everything owned. Customize will become the home for all owned cosmetics; the Emporium will mainly handle discovery and acquisition. Preserve dice selection, dice creation, and the floating 3D model.

The user approved the A+B combination: the Vault collection browser and the Workshop dice editor. Sample inventories and rendered models in the generated concepts are illustrative, not account data or replacement dice materials.

## Constraints
